# Newsletter and download setup

This is an employment-focused professional portfolio. Booking links, prices, service packages and commercial enquiry forms are retired. The legacy `/services/` URL now presents Expertise, and `/hire/` presents the profile for employers.

## Newsletter (optional)

Local writing notes retain an optional newsletter block. Leave `NEXT_PUBLIC_NEWSLETTER_ACTION_URL` empty until a publication is ready. Supply the provider’s public POST endpoint, its email field name in `NEXT_PUBLIC_NEWSLETTER_EMAIL_FIELD`, and any public identifiers in `NEWSLETTER_HIDDEN_FIELDS`. Never place private provider credentials in public fields. Verify confirmation and unsubscribe handling before enabling collection.

## Downloads

`public/downloads/arun-vithyasegar-resume.pdf` is generated from the current `/resume/` page using print CSS. Regenerate it when professional facts change. `WRITING_TEMPLATES` maps four blank CSV worksheets to local writing notes; the worksheets contain no founder or employer data.

## Work samples

Publish only public data, owner-authored blank worksheets, and non-confidential descriptions. Label work in development as ongoing. Never upload internal application trackers, founder details, committee packs, employer records or restricted MCA data. Do not claim affiliation with Guidance Tamil Nadu: it is a career interest, not an employer or client.
