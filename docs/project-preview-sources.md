## Rendering

The existing saved Plotly data and layout were extracted without executing the
notebooks or fetching fresh data. Plotly.js 2.35.2 rendered the figures locally.
Only canvas size (1200 × 650) and margins were changed for legibility; the saved
values, labels, colours, titles, and axes were preserved. Screenshots were
optimised to WebP. Public source-notebook links are pinned to the commits above.

The homepage labels each figure “Saved notebook output”, offers a full-size
image link, and retains the actual dashboard and code links. These are historical
project artefacts, not new findings, current news analysis, or client outcomes.
