## What this does not promise

No page, schema type, crawler rule, or AI text file guarantees indexing, an AI citation, or a top ranking. Google states that the same core SEO foundations apply to AI features; there is no required special AI schema. OpenAI distinguishes OAI-SearchBot (search) from GPTBot (training). Crawler access is one requirement for eligibility, not a promise of visibility. An llms.txt file is not added as a purported ranking mechanism.
